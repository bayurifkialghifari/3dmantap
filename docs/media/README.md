# Demo media

Screenshots and the MP4/GIF walkthrough are captured from the real local application using Playwright and synthetic designs. No customer submission, payment proof, password or private CMS record is included.

The walkthrough covers the storefront, catalog, custom text on a worn shirt, 2D furniture movement and a 3D room with a wall-mounted door and clothed reference human. Loading intervals are removed; remaining footage follows the recorded interactions. The GIF is a smaller preview of demo.mp4.

Media includes renders of bundled third-party models. Human, garments and cabinet components are CC0. Full sources, modifications and license links are in [model-assets.md](../model-assets.md); fonts use the bundled SIL Open Font License files.

Public media is maintained as documentation. Temporary recordings, traces, capture scripts and encoding tools stay in ignored .data storage.
