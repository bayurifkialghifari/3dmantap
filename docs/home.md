# Beranda

## Perilaku

Menampilkan dua studio, template dari database, langkah konsultasi, dan pintu masuk room planner. Tidak menampilkan ulasan atau jumlah pesanan fiktif.

## Kontrak dan data

GET /templates

## Acceptance criteria

Tombol studio mengarah ke katalog yang tepat; halaman responsif desktop dan HP.

## Verifikasi

Jalankan pemeriksaan kualitas README.md. Domain diuji dengan Bun; alur browser dan izin diuji melalui Playwright. Gunakan akun/token terpisah saat memeriksa akses privat.
